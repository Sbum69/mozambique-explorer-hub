# Vendas — materiais para negócios

Materiais para apresentar o EKAYA a negócios locais. Os valores (comissão, destaques, Parceiro
Fundador e lugares em falta) **não estão escritos aqui de propósito**: mudam na janela
Admin → Comissão e preços e aparecem sempre atualizados em `/para-negocios`. Antes de uma visita,
abre essa página e copia os valores em vigor para os campos `[…]`.

| Ficheiro                                     | Para quê                                                          |
| -------------------------------------------- | ----------------------------------------------------------------- |
| [pitch.md](pitch.md)                         | Uma página para enviar ou imprimir                                |
| [whatsapp.md](whatsapp.md)                   | Mensagens curtas (primeiro contacto e seguimento)                 |
| [guiao-visita.md](guiao-visita.md)           | Guião de visita presencial (15–20 minutos)                        |
| [contrato-parceiro.md](contrato-parceiro.md) | Rascunho do acordo de parceria — **revisão jurídica obrigatória** |

Regras: não prometer funcionalidades que não existem (hoje não há pagamento online na aplicação),
não inventar números de visitantes nem testemunhos, e registar cada contacto em Admin → Pedidos
Para negócios.

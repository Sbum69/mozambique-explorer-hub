# Política de segurança / Security policy

## Reportar uma vulnerabilidade

Se encontraste uma falha de segurança no EKAYA Explore, **não abras uma issue pública**. Escreve para
**sheldonesmad@gmail.com** com o assunto `EKAYA — segurança` e inclui:

- o que encontraste e onde (página, pedido, função);
- os passos para reproduzir;
- o impacto que imaginas.

Por favor, não acedas a dados de outras pessoas, não alteres nem apagues dados e não faças testes que
degradem o serviço. Usa só a tua própria conta.

O que fazemos:

- respondemos em até **5 dias úteis**;
- mantemos-te informado até à correção;
- damos-te crédito, se quiseres.

## Reporting a vulnerability

Please **do not open a public issue**. Email **sheldonesmad@gmail.com** with the subject
`EKAYA — security`, describing:

- the issue;
- the steps to reproduce;
- the impact.

Do not access other people's data, change or delete data, or run tests that degrade the service. Use
only your own account.

We reply within **5 business days**.

## Versões suportadas / Supported versions

Só a versão publicada atual (branch `main`). Only the current published version (`main`).
